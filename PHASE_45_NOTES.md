# Phase 45 — Recruiter & Academic Supervisor Experience

Phase 45 adds a role-based portfolio lens without removing or hiding the complete body of work.

## Added
- Five audience/career lenses: Data Scientist, Statistician, Researcher, Software Developer, Tutor / Educator.
- Dynamic profile summary, skills, evidence points and three prioritised projects for each lens.
- Portfolio-wide project highlighting based on the selected lens.
- URL-shareable lens state using `?view=` and local preference persistence.
- Keyboard-accessible role selector and responsive mobile presentation.
- Direct CV and contact actions within the role experience.

## Evidence policy
Role-specific proof points only use work and figures already documented in the preserved portfolio. No employment history, statistical result or credential was invented.

## Preservation
All Phase 44 content, project pages, research intelligence, evidence lab, visualisation studio, accessibility controls and deployment files are retained.
