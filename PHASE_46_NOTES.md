# Phase 46 — Professional Application Mode

Phase 46 converts the Phase 45 career lens into an application-facing experience for recruiters, academic supervisors and collaborators.

## Added
- Role-aware “Why Vivian?” application section on the main portfolio.
- Evidence-weighted skills matrix that changes with the active Phase 45 lens.
- Three-project application shortlist for each professional lens.
- One-page `application-brief.html` for Data Scientist, Statistician, Researcher, Software Developer and Tutor/Educator views.
- Print / Save PDF workflow through the browser print dialog.
- Shareable role-specific portfolio URL copying.
- Direct CV and contact pathways.

## Evidence integrity
The phase reuses documented portfolio evidence and does not invent missing PCA eigenvalues, canonical correlations, factor loadings, model coefficients, ARL/SDRL values or other numerical output not present in the source work.

## Preservation
All Phase 45 role-lens functionality and earlier research, evidence, visualisation, project and deployment layers are preserved.
