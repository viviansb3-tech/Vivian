HONOURS RESEARCH · STATISTICAL PROCESS MONITORING

The Effect of Autocorrelation and Cross-Correlation on Hotelling's T² Control Charts

Simulation-based investigation using R of how dependence among observations influences the performance of the traditional Hotelling's T² control chart.

RESEARCH AIM

The investigation examines how increasing autocorrelation within variables and cross-correlation between variables affect monitored process behaviour and control-chart performance.

METHODOLOGY

Multivariate process data are generated under controlled dependence structures using a bivariate VAR(1) process. Cross-correlation is introduced through the covariance matrix, while autocorrelation is controlled through the autoregressive parameter.

PERFORMANCE MEASURES

ARLAverage Run Length
SDRLStandard Deviation of Run Length

FOUR SIMULATION SCENARIOS

  1. Independent process
  2. Cross-correlated process
  3. Autocorrelated process
  4. Combined autocorrelation and cross-correlation
