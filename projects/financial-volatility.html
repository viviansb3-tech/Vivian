Financial Volatility Modelling

A financial time-series workstream using GARCH-family ideas to model changing conditional variance and understand volatility dynamics.

Research focus

Model periods of changing volatility rather than assuming constant variance throughout a financial series.

Workflow

Inspect returns → assess serial dependence → model conditional mean → specify volatility process → estimate GARCH-family model → diagnose residuals → interpret volatility behaviour.

Technical scope

GARCH-family models, conditional variance, financial returns and time-series diagnostics.

Portfolio value

Adds financial econometrics to the portfolio and complements the Brent–WTI/Bitcoin cointegration project already presented.

MODEL SELECTION

The report compares sGARCH, eGARCH, gjrGARCH and APARCH specifications and selects GJR-GARCH(1,1) with Student-t innovations using the minimum BIC criterion.

VOLATILITY INTERPRETATION

Conditional volatility shows moderate clustering with spikes that revert toward lower levels. The positive leverage estimate indicates negative shocks have the larger volatility impact.
