Exploratory Data Analysis + Data Workflows

A collection of exploratory-analysis workflows developed around real statistical datasets, with emphasis on understanding structure before modelling.

Research focus

Characterise distributions, missingness, relationships, outliers and transformations before selecting downstream methods.

Workflow

Data import → cleaning → descriptive statistics → histograms/density plots → correlation structure → transformations → interpretation.

Tools

R, Excel and statistical packages including psych, ggplot-style visualisation workflows and correlation analysis.

Portfolio value

Shows disciplined data preparation and exploratory reasoning rather than treating modelling as a black box.
