SOFTWARE ENGINEERING / EDUCATION TECHNOLOGY

Full-Stack Tutoring & Virtual Classroom Platform

A web application designed around a real tutoring workflow, combining role-based access, student progress tracking, tutor management and communication in one responsive platform.

Core architecture

Separate Student, Tutor and Administrator portals with private dashboards and role-aware functionality.

Features

Secure registration/login; student-specific screens; tutor profiles and bookings; availability/conflict protection; grading; homework/materials; progress graphs; messaging; audit logging; persistent SQLite data.

Real-time classroom concept

A virtual classroom workflow with a Need Help / Raise Hand alert system, tutor notification queue and real-time assistance architecture using WebSockets/Socket.io concepts.

Portfolio value

Demonstrates the ability to turn a real education problem into a structured software product with database, UI, role management and operational workflows.
